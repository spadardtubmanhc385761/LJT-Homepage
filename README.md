# LJT-Homepage

Personal academic homepage of **Junteng Liu**, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (forked from [`academicpages/academicpages.github.io`](https://github.com/academicpages/academicpages.github.io)).

## Structure

- `_config.yml` — site-wide configuration and author profile.
- `_pages/about.md` — the home / about page (personal details, education, research experience, publications, skills, and contact information).
- `_pages/publications.html` and `_publications/` — the publications list.
- `_data/navigation.yml` — header navigation.
